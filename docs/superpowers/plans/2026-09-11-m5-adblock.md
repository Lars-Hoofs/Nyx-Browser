# Nyx M5 — Adblock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Content blocking per spec §5.6: EasyList/EasyPrivacy converted via AdGuard's SafariConverterLib, compiled into cached WKContentRuleLists, applied per-tab so blocking can be toggled per site — with a first-run compile off the critical path and every failure degrading to unblocked browsing.

**Architecture:** NyxCore gains the converter wrapper (`FilterListConverter` over ContentBlockerConverter), bundled filter-list snapshots as package resources, and schema v4 (`site_override` table + FTS prefix indexes — the carried launcher-perf item). The Shell gains `RuleListManager` (compile off-main into `WKContentRuleListStore` under versioned identifiers, `lookUpContentRuleList` on launch, failure → unblocked + background retry) and applies lists through the existing attach funnel (`BrowserTab.attach` → per-tab `WKUserContentController`), covering hibernation re-attach and the popup-shares-opener-controller caveat. UI: menu items (global toggle + per-site toggle with reload) — the minimal settings surface; a full settings window is a later milestone.

**Tech Stack:** + `SafariConverterLib` (AdGuard, SPM, product `ContentBlockerConverter`) pinned to its current major — the ONLY new dependency, NyxCore-only. Bundled EasyList/EasyPrivacy snapshots (with license attribution) instead of runtime downloads — deterministic and offline-testable; a background updater is deliberately deferred (recorded scope ruling).

**Spec:** docs/superpowers/specs/2026-09-11-nyx-browser-design.md §4 (per-site overrides), §5.3 (per-tab controllers), §5.6 (adblock), §6 (failure rows), §9 M5.

## Global Constraints

- Everything from M1–M4 binds. Branch `m5-adblock` from main (post-M4).
- **Speed protocol (ruled):** implement serially, but the controller overlaps review(N) with implement(N+1). Battery tiering: NyxCore-only tasks verify with `make build` + `make test-core` (+`make test-unit` when the unit bundle consumes the change); Shell/UI tasks and milestone gates run the full battery (now 10 UI tests). `-only-testing` while iterating; full suite once per task end.
- Rule lists: ≤150,000 rules per compiled list (WebKit cap); 2–3 lists (ads, privacy); compile NEVER on the main thread and NEVER blocks first paint; compile failure or missing cache → pages load unblocked, retry in background, NSLog — never a dialog, never a crash (spec §6).
- Per-site override semantics: override keyed by registrable-ish host (lowercased `URL.host`); default = blocking ON; override rows exist only for OFF sites. Toggling requires a reload of affected tabs — do it automatically for the acting tab.
- Popup caveat (M4 review): adopted popups share the opener's `WKUserContentController` — the apply/remove path must handle a controller that serves multiple tabs (treat the popup as inheriting the opener's site override at adoption; re-evaluated on its next attach).
- Hibernation: every `attach()` must (re)apply the correct lists for the tab's current site before/immediately after the webview starts loading.
- New a11y/menu identifiers: menu items "Block Ads" (global) and "Block Ads on This Site" under a new "Nyx" > … no — View menu section; exact placement per task brief.
- Non-goals M5: runtime filter-list updater, advanced/scriptlet rules ("enhanced blocking" — spec marks it off-by-default anyway), YouTube ads, cosmetic-filter UI, full settings window, allowlist import.

### Task 1 [CORE]: SafariConverterLib + FilterListConverter (TDD)

**Files:** `NyxCore/Package.swift` (+dep), `NyxCore/Sources/NyxCore/FilterListConverter.swift`, `NyxCore/Tests/NyxCoreTests/FilterListConverterTests.swift`

**Interfaces:**
```swift
public struct ConvertedRuleList: Equatable {
    public var identifier: String      // e.g. "ads-v<contentHash8>"
    public var json: String            // WebKit content-blocker JSON
    public var ruleCount: Int
    public var discardedCount: Int     // rules the converter could not express
}
public enum FilterListConverter {
    /// Converts AdBlock-syntax filter text to WebKit JSON. Splits output
    /// so no list exceeds maxRules (default 150_000). Identifier embeds a
    /// stable hash of the SOURCE text so cache lookups are content-addressed.
    public static func convert(name: String, filterText: String,
                               maxRules: Int = 150_000) throws -> [ConvertedRuleList]
}
```
TDD with a small fixture (a dozen representative rules: network block, exception, element-hide, a rule the converter rejects): JSON non-empty and parseable, counts plausible, identifier stable across calls and different across differing input, oversized synthetic input splits. Verify the SPM product name (`ContentBlockerConverter`) against the resolved package; adapt + record if it differs.

Battery: build + test-core (+resolution network note). Commit: `feat(m5): FilterListConverter over SafariConverterLib`

### Task 4 [SHELL]: RuleListManager

**Files:** `Nyx/Shell/RuleListManager.swift`, NyxTests coverage.

**Interfaces:**
```swift
@MainActor final class RuleListManager {
    init(store: WKContentRuleListStore = .default())
    private(set) var compiledLists: [WKContentRuleList]   // empty until ready
    var isReady: Bool { get }
    var onReady: (() -> Void)?
    /// Launch path: lookUp cached identifiers; on miss, convert+compile the
    /// bundled lists on a background task, store under content-addressed
    /// identifiers, prune stale identifiers, then flip isReady on main.
    func bootstrap()
    func apply(to controller: WKUserContentController)     // adds all compiled lists
    func remove(from controller: WKUserContentController)  // removeAllContentRuleLists
}
```
Failure semantics per constraints (unblocked + NSLog + one background retry after 30s). Unit tests: bootstrap-from-cache path with a tiny pre-compiled fixture list (compile a 2-rule JSON in-test — WKContentRuleListStore works headless), apply/remove round-trip on a real controller, failure path (corrupt JSON → isReady stays false, no throw).

Battery: full. Commit: `feat(m5): RuleListManager — cached compile, apply/remove`

### Task 5 [SHELL]: Per-tab application through the attach funnel

**Files:** `Nyx/Shell/BrowserTab.swift` (+`var currentHost: String?` derived on commit; apply hook), `Nyx/Shell/TabManager.swift` (inject RuleListManager + SiteOverrideStore access via closures), `Nyx/Shell/NyxWindowCoordinator.swift` (wiring), NyxTests.

Behavior: on `attach()`, after delegates are set: if blocking globally on AND site not overridden → `ruleLists.apply(to: webView.configuration.userContentController)` else `remove`. On committed navigation to a DIFFERENT host with a DIFFERENT override state → re-evaluate (apply/remove + no auto-reload — the new load already ran under the right state iff evaluated BEFORE load; ensure ordering: evaluation happens in attach and in `decidePolicyFor`-equivalent timing — practical rule: evaluate in attach + on didCommit host change, accepting that the first committed load after a cross-override navigation may need the reload the TOGGLE path performs; document). Toggle path (Task 6) re-evaluates + reloads the acting tab. Popup adoption: inherit opener's evaluation (shared controller — record semantics). Unit tests: attach applies/skips per override; hibernate→re-attach reapplies; toggle-evaluate path (closure-level).

Battery: full. Commit: `feat(m5): per-tab rule application with site overrides`
